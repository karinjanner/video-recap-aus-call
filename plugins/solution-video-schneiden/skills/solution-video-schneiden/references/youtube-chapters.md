# YouTube-Kapitel

Wenn eine Vollaufnahme, eine Endfassung oder ein Transkript für YouTube aufbereitet werden soll, zusätzlich eine direkt einsetzbare Kapitelliste erstellen.

- Kapitel an echten Themenwechseln setzen: nicht kleinteilig, aber auch nicht so grob, dass wichtige Themen schwer auffindbar werden.
- Format je Zeile: `Zeitstempel Sprechername: Kapitelinhalt`.
- Zeitstempel immer zuerst, damit YouTube ihn als klickbares Kapitel erkennt.
- Bei mehreren maßgeblich beteiligten Personen alle bestätigten Namen nennen.
- Sprecherzuordnung und Schreibweise anhand von Anreden, Bild, Transkript oder anderen belastbaren Signalen prüfen; Namen nie raten.
- Liste mit `0:00` beginnen, chronologisch sortieren und unter der Überschrift `KAPITEL` ausgeben.
- Zeitstempel auf die tatsächlich auszuliefernde Datei beziehen, nicht ungeprüft auf Originalzeitcodes der Aufnahme.
